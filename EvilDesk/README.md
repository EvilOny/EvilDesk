# EvilDesk Controller

Аддон для управления Яндекс Музыкой через WebSocket.

## Функции
- 🎵 Отображение названия трека и исполнителя
- 🖼️ Обложка альбома
- ▶️⏸️ Управление воспроизведением
- ⏮️⏭️ Переключение треков
- ❤️ Лайк/дизлайк

## Настройки
- **IP адрес**: адрес Python-сервера (по умолчанию `127.0.0.1`)
- **Порт**: порт WebSocket (по умолчанию `8080`)

## Требования
- Запущенное приложение [EvilDesk Player](https://github.com/yourrepo/evildesk-player)
- PulseSync v1.0+
